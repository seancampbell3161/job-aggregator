# Relevance profile

The LLM scores each keyword-passing job posting against this profile to produce
a 0–10 relevance number plus a one-sentence rationale. This file is a template —
copy it to `profile.md` and rewrite every section as if you're briefing a
recruiter. The *shape* matters more than the exact text: plainly-stated signals
("IC only", "US-based only") are what the LLM picks up reliably.

## Quick summary

Backend-leaning fullstack engineer with ~6 years of professional experience.
Daily driver is Python (FastAPI, Django) with PostgreSQL, plus React/TypeScript
on the frontend. Comfortable in Go and Node.js but not fastest there.

Looking for a permanent, full-time employee role. US-based only. Remote (US)
works from anywhere; hybrid and on-site work in Chicago or Denver.
Comp target $130k+ base. Mid or senior IC level — not interested in the
management track or staff/principal ladder.

## Stack depth

**Primary** (production code this year, productive on day one):
- Python (FastAPI, Django, SQLAlchemy)
- PostgreSQL (schema design, query tuning)
- React + TypeScript

**Familiar** (shipped within ~2 years; days to ramp back up, not weeks):
- Go
- Node.js
- AWS (ECS, Lambda, RDS)

## Strong fit (8–10 score territory)

- Product engineering / fullstack feature work — building things end-users
  touch, at any company stage.
- Backend / API / distributed-systems work: services, schemas, REST/gRPC.
- Python-first teams; a TypeScript-heavy product team is a strong fit too.
- Roles that say "5+ years", "mid-level", or "senior" plainly.

## Mild fit (5–7 score territory)

- Platform / SRE-adjacent / infrastructure roles — interesting, not the pull.
- Data engineering (pipelines, warehouses) — adjacent to my backend work.
- Pure frontend on a top-tier product.

## Weak fit / not interested (1–3 score territory)

- **Any role whose primary location is outside the United States.** Score ≤ 2
  for postings tagged with non-US cities or "EU-remote" / "EMEA" / "APAC"
  listings. This constraint is hard — visa transfer is not on the table.
- Contract-only, agency, or consulting roles.
- Staff / principal / distinguished titles; engineering manager or any
  management-track title. IC only.
- New-grad, junior, "0–2 years", intern roles.
- On-site or hybrid roles in a US city I can't commute to — anywhere outside
  Chicago or Denver. Score low **for location**, not for being on-site.
- Roles requiring active security clearance.
- Roles for languages I haven't shipped: Rust, C++, Scala, Ruby, PHP.

## What I care about beyond the role

- Async-first culture, written communication over meetings.
- Reasonable code review and modern tooling (CI/CD, type checking).
- Some autonomy on technical decisions within my area.

A posting doesn't have to mention these explicitly — if the description sounds
like a healthy engineering org, that's a positive signal.
