Guided setup

Walks you through an LLM, your résumé, what counts as a good match, which boards to poll, and where alerts go — drafting your profile and filters from your résumé along the way. Every step is skippable.

Start from defaults

Creates an empty settings version and opens Settings. Nothing is polled or delivered until you add job titles, a company board, and a notification target — the Overview page tracks what is still missing.

Restore from a backup

Restores settings, your profile, and résumé documents from a downloaded backup (.zip). Secrets — the ntfy topic, Discord webhook, and API keys — are never included in a backup; set them again on the Notifications and LLM pages afterwards.

Or import existing files

Docker Compose

From the directory holding your config.yaml (start from config.example.yaml) and, optionally, profile.md, resume.md, and resume/:

docker compose run --rm -v "$PWD:/import:ro" web python -m src.settings import /import

Secrets (ntfy topic, Discord webhook, API keys) can stay in .env, or be copied into the database:

docker compose run --rm web python -m src.settings import-env-secrets
docker compose run --rm -it web python -m src.settings set-secret ntfy_topic_url

Without Docker

python -m src.settings import .

Check the result with python -m src.settings status, then reload this page.
