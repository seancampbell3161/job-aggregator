A backup is one zip file with everything needed to stand this instance up again: settings, your profile, your résumé documents, and any résumé template packs you've uploaded. It does not include secrets — API keys, webhook URLs, and the tailoring signing secret stay out of the file; reconnect those by hand (or with import-env-secrets) after restoring elsewhere.

Download backup (.zip)

Restore from a backup

Restoring replaces the current settings, profile, and résumé documents with what the archive holds, written as one new settings version. Nothing is written until the archive is fully validated.
